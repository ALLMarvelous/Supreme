# Supreme

A Muse Dash mod that shows hidden (Supreme) charts as a fourth difficulty on the song preparation screen, next to Easy, Hard and Master.

## Usage

Songs with a hidden chart get a **SUPREME** button. Click it, or move to it with left/right, then start the song.

## Building

Set `MD_DIRECTORY` to your Muse Dash folder and run `dotnet build -c Release`. The DLL is copied to the game's `Mods`
folder.
